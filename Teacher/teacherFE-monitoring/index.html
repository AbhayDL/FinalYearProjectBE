Anti-Cheat Monitoring

The Anti-Cheat Monitoring Screen records student activities such as tab switching, copy-paste actions, and session behavior. This enhances the reliability and integrity of the examination process by helping teachers review suspicious patterns with clear evidence.

Purpose

Evidence-based monitoring for examinations

This review screen helps teachers inspect suspicious activity through recorded session signals. It is intended to support fair academic review with explainable indicators rather than hidden or automatic punishment.

Signals Tracked
  • Tab switching and page visibility changes
  • Copy and paste attempts during coding sessions
  • Fullscreen exits and returns
  • Window blur and inactivity behavior
  • Run, save, and submission actions
Teacher Review
  • Select a student from the monitoring list
  • Filter monitored problems by subject
  • Open the student problem review player
  • Use signals as supporting evidence, not final verdicts
